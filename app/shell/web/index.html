手动上传核心

网络不通或想指定版本时使用。到 Releases 下载对应架构的 vnts2-<架构>-unknown-linux-musl-v<版本> 文件（无扩展名）。

下载源与代理

不带端口的加速地址填这里，请求会拼成 前缀/https://github.com/...

支持 HTTP / HTTPS / SOCKS5，必须带端口；保存前会实测，连不通则不保存。
SOCKS5 两种写法：socks5:// 由本机解析域名， socks5h:// 把域名交给代理解析（远端 DNS，内网域名用它）。

服务端设置

网络参数

新网络编号使用的默认网段（IPv4 CIDR）
逗号分隔。非空时只有列表内的编号才能加入
离线超过该时长的设备，虚拟 IP 会被回收

控制台管理员

用于登录/内嵌控制台。修改后自动重启核心生效

协议开关与端口

默认三者复用「组网服务端口」；需要分开监听或避开端口占用时，在此填独立端口。 WSS 与 TCP 同端口时自动复用 TLS。

端口

改动管理页端口后需重新访问新端口

服务端互联（可选）

此处只控制本机是否接受其它服务端连入。要主动连出到别的服务端，请用下方「出站互联域名」。

出站互联域名

vnts2 只接受 IP:端口，填域名它解析不了。这里填的域名由管理页定时解析成当前 IP， 再自动同步进互联列表 —— 域名 IP 变了会自动换，无需重启核心。

配置导入导出

导出服务器配置

打包 config.toml（唯一配置文件）、数据库（网络/设备记录）与证书。 不含日志与核心二进制。用于迁移到新机器或备份。

导入服务器配置

选择之前导出的 zip。导入前会自动备份现有配置，失败自动回滚。 导入后核心会自动重启。

日志目录

日志与配置分开存放。迁移时只需拷走配置目录，日志无需保留。

vnts2 日志级别与轮转

debug 会输出大量连接细节，排查问题时才需要；平时用 info。 修改后约 30 秒内自动生效，无需重启核心。

超过即滚动到下一个文件。 用 512 KB · 用 10 MB （历史上界面只留最近一段日志，看起来像「512K 就覆盖」，现已可自由设定）
